# AETech Academy: Leadership & Collaboration

Welcome to your first module at AETech Academy! Engineering is not just about writing code; it's about communicating effectively with your team.

## Your Task

1. Create a file named `proposal.md` in this repository.
2. Write a technical proposal for a fictional feature you want to build. Your proposal MUST be at least 150 words.
3. Commit and push your changes to the `main` branch.

Once you push, the automated grader will check your work. Good luck!
